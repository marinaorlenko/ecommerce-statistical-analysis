# Статистический анализ данных электронной коммерции

Учебный проект по статистическому анализу поведения посетителей интернет-магазина, конверсии и сумм покупок. Исследование выполнено в Jupyter Notebook на Python.

## Цель исследования

Изучить характеристики данных и покупательского поведения, сравнить методы формирования выборок, оценить статистические показатели и их неопределённость, проверить гипотезы о различиях между сегментами и сформулировать бизнес-рекомендации с учётом ограничений анализа.

## Данные

Исходный файл: `data/dataset.csv`.

Набор данных содержит 5 000 наблюдений за период с 1 января по 29 июня 2025 года. Каждая строка соответствует одному уникальному посетителю (`customer_id`) и содержит сведения о его посещении и покупке.

Рассматриваются возраст, пол, регион, источник трафика, рекламная кампания, время на сайте, количество просмотренных страниц, факт покупки, сумма покупки, количество товаров, срок доставки и удовлетворённость.

Для посетителей без покупки сумма покупки равна нулю; часть показателей заказа к ним неприменима. Отсутствие значения рекламной кампании для источников, отличных от `PaidAds`, имеет структурный характер.

## Содержание исследования

- **A.** Первичный анализ данных и описательная статистика.
- **B.** Формирование выборок различными методами.
- **C.** Анализ репрезентативности выборок.
- **D.** Доверительные интервалы.
- **E.** Центральная предельная теорема.
- **F.** Анализ распределения положительных сумм покупок и подбор теоретического распределения.
- **G.** Свойства статистических оценок: смещение и состоятельность.
- **H.** Бизнес-анализ: кампании, источники трафика, регионы, поведенческие показатели, рекомендации и статистические ограничения.

## Основные результаты

- Распределение сумм покупок среди покупателей имеет выраженную правостороннюю асимметрию; средний чек составляет 95,96, медиана — 52,88.
- Статистически значимых различий конверсии между рекламными кампаниями, источниками трафика и регионами не выявлено на уровне значимости 0,05.
- Распределения сумм покупок различаются между регионами: в попарных сравнениях подтверждены различия между `East` и `North`, а также между `East` и `South`.
- Время пребывания на сайте статистически значимо различается между покупателями и посетителями без покупки. Наблюдаемая конверсия последовательно увеличивается от 13,39% в первом квинтиле до 67,60% в пятом квинтиле времени пребывания на сайте.
- Количество просмотренных страниц не показало статистически значимых различий между покупателями и посетителями без покупки. Значимой монотонной связи времени на сайте и глубины просмотра с суммой покупки среди покупателей также не обнаружено.

Результаты описывают статистические связи, но не доказывают причинно-следственные зависимости. Данные не содержат рекламных расходов и точного момента покупки внутри посещения.

## Бизнес-рекомендации

На основании результатов статистического анализа сформулированы следующие рекомендации:

1. **Развивать поведенческую аналитику.** Время пребывания на сайте демонстрирует выраженную связь с конверсией. Рекомендуется дополнить данные событиями пользовательских сессий и исследовать поведение до момента покупки. Потенциальные сценарии персонализации следует проверять с помощью A/B-тестов.

2. **Изучить региональные различия в покупках.** В регионе `East` наблюдается наиболее высокий средний чек (104,28), а распределения сумм покупок статистически значимо отличаются от регионов `North` и `South`. Рекомендуется проверить ассортимент, структуру заказов и характеристики покупателей, которые могут объяснять эти различия.

3. **Оценивать эффективность рекламных кампаний с учётом затрат.** Несмотря на различия наблюдаемых показателей, статистически значимых различий конверсии между кампаниями и источниками трафика не выявлено. Не рекомендуется перераспределять бюджет только на основании текущих результатов. Для оценки эффективности необходимо дополнить данные рекламными расходами и рассчитывать CAC и ROAS.

4. **Учитывать асимметрию распределения сумм покупок.** Из-за влияния крупных заказов средний чек существенно превышает медиану. При оценке покупательского поведения рекомендуется использовать оба показателя, анализировать квантили и отдельно исследовать сегмент крупных покупок.

5. **Проверять бизнес-гипотезы на новых данных.** Обнаруженные статистические связи не доказывают причинного влияния исследованных факторов. Перед внедрением изменений рекомендуется оценивать величину эффекта, экономическую целесообразность и результаты контролируемых экспериментов.

## Установка и запуск

Требуется Python 3.10+ и Jupyter Notebook или среда, поддерживающая файлы `.ipynb` (например, VS Code с расширением Jupyter).

Из корня проекта создайте и активируйте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
python -m pip install notebook
```

Откройте `notebooks/statistical_analysis.ipynb` в Jupyter или VS Code и выполните ячейки последовательно.

Пути к данным и отчётам заданы относительно каталога `notebooks/`, поэтому рабочим каталогом Notebook должен быть `notebooks/`.

Графики сохраняются в `reports/figures/`.
